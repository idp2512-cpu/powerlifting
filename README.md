# Powerlifting Club — Вебсайт про силове триборство

Цей проєкт створено в межах виконання практичної роботи №18 з публікації та реєстрації сайтів за допомогою GitHub та GitHub Pages.

 Опис проєкту
Інформаційний вебресурс, присвячений паверліфтингу. На сайті розміщено базову інформацію про цей вид спорту, опис трьох основних змагальних вправ (присідання, жим лежачи, станова тяга) та корисні поради для початківців.
